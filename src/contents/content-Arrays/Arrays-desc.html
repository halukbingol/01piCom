• Before execution: the array nums does not exist yet.
  • int[] nums = new int[5]; creates a new array of 5 ints on the heap. Every element starts at Java's default value for int, which is 0.
  • nums[0] = 10; stores 10 in the element at index 0.
  • nums[1] = 20; stores 20 in the element at index 1.
  • nums[2] = 30; stores 30 in the element at index 2.
  • nums[3] = 40; stores 40 in the element at index 3. Index 4 keeps its default value, 0.
  • int sum = nums[0] + nums[1]; reads nums[0] and nums[1] and stores their sum, 30, in sum.
